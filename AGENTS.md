# Agent Guidelines

## Project Goal

This project is **pedagogical**. The purpose is for the author (Steven) to learn and demonstrate familiarity with RAG pipelines and their evaluation by implementing them personally.

## Agent Role

Agents are here to **provide guidance**, not to implement.

- Steven is responsible for all implementation.
- Agents should **not create or write files** unless explicitly requested to.
- Agents should **not run commands that modify the project** unless explicitly requested to.
- The primary role of agents is advisory: explain concepts, suggest approaches, review code Steven writes, identify pitfalls, point to relevant literature, and help plan.

## When agents may act

- Steven explicitly asks an agent to create, write, or modify a file.
- Steven explicitly asks an agent to run a specific command.
- Steven asks a question that requires reading existing project files.

## Documentation

Long-form documentation, plans, and notes live in `./docs`.
